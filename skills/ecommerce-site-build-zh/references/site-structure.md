# 网站结构参考（独立站 / 跨境电商）

方向稿和样板页都按这套结构来。老站改版时以"保持用户说不能动的部分"为准，下面的结构用来查漏补缺。依据主要是 Baymard Institute 的电商 UX 研究和 Shopify 官方的跨境建议。

## 全局

- **公告栏**：放最重要的一条承诺（包邮门槛、发货时效），可轮播 2–3 条。
- **页头**：logo、主导航（一级建议不超过 7 项，每层子分类约 10 个以内，一级标题本身也可点击）、搜索、账户、购物车、币种 / 语言切换。
- **页脚**：Shop（主要分类）、Help（配送、退换货、FAQ、联系我们、订单追踪）、About（品牌故事、博客、批发 / 合作）、Legal（隐私、条款、退款、配送政策）、邮件订阅、社媒、支付方式图标。

## 首页（自上而下）

1. 首屏：一句话价值主张 + 主按钮（去主推分类）+ 次按钮（如样品 / 入门款）
2. 信任条：评价分数和数量、包邮 / 退换承诺、产地或工艺卖点（3–4 项）
3. 畅销品
4. 按分类逛（每个分类配代表图）
5. 品牌故事 / 工艺证明（图文分栏，配可验证的细节）
6. 新品或重点系列
7. 教育内容 / 怎么用
8. 真实评价或 UGC（只用评价 app 里的真实评价）
9. 媒体报道 / 合作（有才放）
10. 博客文章
11. 邮件订阅

首页不要塞太多广告位；轮播每 5–7 秒切换，手机端关掉自动轮播。

## 分类页（Collection / PLP）

- 标题 + 2–3 行简介（长的 SEO 文案放到商品列表下面）
- 筛选器：桌面端放侧栏，手机端用抽屉；同一筛选项允许多选；显示已选筛选条件，可一键清除
- 排序至少有：畅销、最新、价格、评分
- 商品卡：悬停显示第二张图、价格、星级和评价数、快速加购；同款不同规格合并成一张卡
- 多规格商品显示单位价格（如每克 / 每件）

## 产品页（PDP）——转化最关键

- **图片区**：至少 3 张，包含能看出尺寸的图；视频可选
- **购买区（首屏内）**：标题、星级 + 评价数（可跳到评价区）、价格、规格用按钮而不是下拉框、加购按钮 + 快捷支付、加购按钮附近写清运费 / 包邮门槛、预计送达、退换政策
- **关键卖点行**：3–4 个图标短句（产地、规格、认证等）
- **描述**：纯文字、分段清楚；图片放进产品图库而不是塞在描述里
- **规格表**：结构化参数（建议用 metafield，方便筛选和复用）
- **使用方法 / FAQ**
- **评价区**：真实评价，回复差评；评价图片可以跨评价浏览
- **测评 / UGC 区**（如果有）：KOL 视频、博客测评，单独成区，放在描述下方，并在购买区放一个跳转链接
- **搭配推荐 / 相关商品**
- **手机端吸底加购栏**
- **结构化数据**：Product JSON-LD（价格、库存、评分）

## 购物车与结账

- 抽屉式购物车，带"再买 $X 包邮"进度条、搭配推荐、快捷支付。
- 总费用要提前透明：Baymard 数据显示约 39% 的弃单是因为运费、税费等额外费用出现得太晚；19% 是因为被迫注册账户。所以支持游客结账，运费在 PDP 和购物车就说清楚。

## 内容与信任页

- About（品牌故事、创始人、时间线、产地 / 工厂实拍）
- Blog（教程、选购指南，文中嵌商品）
- FAQ、Contact（响应时间、邮箱）、订单追踪
- 批发 / B2B 询盘页、达人 / 联盟计划页、会员积分页（按业务需要）

## 跨境专项

- 多币种（Shopify Markets 等），价格取整规则
- 关税和税费说明：DDP（含税到家）还是 DDU（收货时付），在配送政策和购物车写清楚
- 按地区的运费和送达时间表
- 当地常用支付方式
- 多语言：子目录（`/en-gb/`）+ hreflang；翻译要用当地搜索习惯的词
- 隐私合规：Cookie 同意弹窗（GDPR）、隐私政策覆盖目标市场法规（GDPR / CCPA / PIPEDA 等）
- 不做无法证实的宣称（功效、"organic" 等认证词），这些在海外广告平台和消费者法规下都有风险

## 追踪与 SEO

- 每个事件只有一个来源（例如 GA4 走官方 app，GTM 走自定义像素），上线前确认购买事件不重复计数
- 每页一个 H1；meta 标题和描述；图片 alt
- 改版改了 URL 就做 301 重定向
- `/collections/all` 这类页面 noindex
